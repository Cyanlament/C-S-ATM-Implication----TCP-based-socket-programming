## 二、实验目的

1. 理解基于 TCP 的自定义应用层协议设计方法。
2. 掌握 ATM 客户端与银行服务器端之间的 Socket 通信流程。
3. 实现用户认证、余额查询、支取和退出等核心业务逻辑。
4. 使用文本文件实现用户口令和账户余额的持久化管理。
5. 掌握服务端状态机和多客户端并发处理方法。
